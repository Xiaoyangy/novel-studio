# 创作直播看板

当前源码版 Dashboard 提供 `/broadcast`，也可从看板首页点击“直播模式”进入。它展示实际运行记录，而不是演示动画；本次执行停止或出错时，会保留最后工作位置并明确提示未在执行。

## 本机直播

启动当前源码中的 Dashboard，打开其 `/broadcast` 地址。例如：

```bash
python3 services/dashboard/server.py --host 127.0.0.1 --port 8766
```

默认读取 `data/runs`。需要其他书目目录时，设置 `NOVEL_STUDIO_RUNS_DIR` 为包含各个运行目录的父目录。已有服务可直接使用原端口的 `/broadcast`；旧 Release 必须升级到包含本功能的版本。

在 OBS 中添加“浏览器”来源，将地址设为 `http://127.0.0.1:8766/broadcast`，建议画布 **1920 × 1080**。浏览器内也可使用“全屏”或 `F`；“净屏”隐藏操作区，`Esc` 恢复。

- 页面约每 3 秒取一次快照，后台缓存约 2 秒，并避免重复并发扫描。
- “暂停画面”只暂停页面刷新，不暂停小说进程。后台标签页暂停请求，重新可见时恢复。
- 断线会保留最后快照并提示陈旧状态，不会冒充仍在实时执行。
- 选择书目后，地址中的 opaque ID 可以固定 OBS 对应的书目。

## 口径和安全边界

角色决定、世界周期、正式章节计划与已验收正文分别计数。周期增加不等于多写了一章；装饰性动效不代表百分比进度。故事时钟来自已绑定的持久会话。

用量只覆盖页面标注的**角色推演审计**，不是整本书从初始化开始的全部账单。估算、部分计价与未知金额明确区分；未知值显示 `—` 或“未计价”。

直播专用 API 使用字段白名单，只返回标题、角色名、受限状态、计数及里程碑；不返回私人路径、PID、原始日志、提示词、角色私有记忆、思维链或剧情原文。出错响应也不展示底层异常路径。

**直播视图不是身份认证或公网访问控制。** Dashboard 的其他管理/详情接口仍是本地工具，请保持绑定 `127.0.0.1`，不要直接将整个服务暴露到公网。需要直播时捕获本页，不要同时捕获终端、地址外的其他页面或本地文件。
